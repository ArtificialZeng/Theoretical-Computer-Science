## コードと再現性

以下をリポジトリのルートで実行する。一課題だけなら --all を --paper ID に置き換える。Python 3.10+ が必要で、一部には Rust、Node.js、科学計算用Pythonパッケージ、専用ツールも必要である。PDF構築には LaTeX、latexmk、Poppler を使う。各課題のリンク先に手順と依存関係がある。有限検査は明示された事例のみを覆い、一般証明の代わりではない。

```sh
git clone https://github.com/ArtificialZeng/Theoretical-Computer-Science.git
cd Theoretical-Computer-Science
python3 scripts/verify_artifacts.py
python3 scripts/reproduce.py --all
python3 scripts/build_pdfs.py --all
```
