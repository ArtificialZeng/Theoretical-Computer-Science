### Truly Subquadratic 3SUM over Every Bounded-Exponent Abelian Group

**Résumé.** Donne un algorithme randomisé véritablement sous-quadratique pour détecter une somme nulle de trois listes et retrouver un témoin dans tout groupe abélien fini compact, d’exposant fixé borné et d’ordre polynomial. Le gain d’exposant ne dépend pas du degré polynomial de l’ordre du groupe. Des profils simultanés des classes initiales et un certificat extrémal de diviseur équilibrent tous les ordres de torsion autour d’un algorithme matriciel existant. Le temps au pire cas est plafonné et le succès unilatéral vaut au moins 3/4 ; toute relation finie fixe représentable par un groupe abélien bénéficie aussi d’un algorithme sous-quadratique.

**Résumé.** Donne un algorithme Exact Triangle déterministe véritablement sous-cubique pour tout groupe abélien fini compact, d’exposant fixé borné et d’ordre polynomial. ### A Sparse-Cardinality Curvature Bound under Persistent Adversarial Noise

## Code et reproductibilité

Exécuter les commandes ci-dessous à la racine. Pour un sujet, remplacer --all par --paper ID. Python 3.10+ est nécessaire ; certains fichiers demandent aussi Rust, Node.js, des bibliothèques Python scientifiques ou des outils spécifiques. Compiler les PDF exige LaTeX, latexmk et Poppler. Les instructions par sujet précisent étapes et dépendances. Les tests finis ne couvrent que leurs cas documentés et ne remplacent pas les preuves générales.

```sh
git clone https://github.com/ArtificialZeng/Theoretical-Computer-Science.git
cd Theoretical-Computer-Science
python3 scripts/verify_artifacts.py
python3 scripts/reproduce.py --all
python3 scripts/build_pdfs.py --all
```

catalog.json constitue l’index unifié lisible par machine ; readiness.json contient les deux catégories. Les anciennes URL restent valables.
