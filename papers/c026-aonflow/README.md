# A Near-Logarithmic Approximation for All-or-Nothing Flow

**working_paper** · 7 total pages.

[PDF](c026-aonflow_working_paper.pdf) · [Unified index](../../README.md)

Selects as many terminal pairs as possible so that each selected pair sends one splittable unit through an undirected unit-capacity graph with congestion one. A randomized polynomial-time algorithm attains a log^(1+o(1)) k approximation, with feasible output on every run and the cardinality guarantee with probability at least 3/4. It combines prior flow-expander decomposition and matching rounding with a charged admission interface. The verified version has 7 pages; a 16-page expanded version is also preserved.
