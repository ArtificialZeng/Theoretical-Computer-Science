# Arena-Independent Memory for Pure Subgame-Perfect Equilibria in Reachability Games

**working_paper** · 8 total pages.

[PDF](c022-spe-memory_working_paper.pdf) · [Unified index](../../README.md)

Studies how much memory pure subgame-perfect equilibria need in turn-based games with Boolean reachability objectives. Every equilibrium winner set can be preserved with at most n·3^n states per player, independently of arena size and branching, even on set-sized infinite arenas. A promise-reset construction handles every legal history; a finite family supplies an exponential lower bound. The dependence on player count is exponential in order, without a sharp optimal base.
