# Polynomial-Time Construction of Vertex-Fault-Tolerant Mixed-Stretch Spanners

**working_paper** · 7 total pages.

[PDF](c029-vftfast_working_paper.pdf) · [Unified index](../../README.md)

Constructs vertex-fault-tolerant spanners at the known mixed-stretch tradeoff (Oδ(√k), Oδ(k)) and edge bound Õδ((f+1)^(1+δ)n^(1+1/k)), now in deterministic polynomial time with exponent depending only on fixed δ. Representative path families and protected length-bounded cuts handle one parameter regime; an existing multiplicative construction covers the complement. The advance is efficient construction throughout the tradeoff, rather than improved stretch or sparsity.
