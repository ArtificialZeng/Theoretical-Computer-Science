# Sparse Discrepancy Beyond Additive Functions: Acyclic, Bounded-Degree and Degenerate Sparsity Patterns

**working_paper** · 54 total pages.

[PDF](q14-sparse-discrepancy_working_paper.pdf) · [Unified index](../../README.md)

Studies a nonadditive Beck–Fiala question: can t-sparse families of 1-Lipschitz set functions always be balanced with discrepancy depending only on t? This existing partial manuscript gives pattern-dependent bounds for t=2, including max(2,d) for degeneracy d and 3 for planar patterns, using antipodal cube separation and function-deletion transfers; exact finite computations accompany several small cases. The general question remains open, even for dense 2-sparse patterns. The 54-page draft is archived as working_paper, without a new full-resolution or STOC-readiness certification.
