# 论文与后续交接

本稿题为 *Matching Advice on Degree-Two Bipartite Graphs: Exact
Consistency–Robustness Frontiers*。作者及顺序为 Zijian Zeng、Jiayin Cao、
Weinan Dai、Rui Wang、Fei Ding；机构及邮箱使用用户给定内容。

已接受的数学范围：简单无权二分图、两侧最大度至多二、在线点逐个到达、
不可撤销的整数匹配、图/顺序/建议预先固定的 oblivious adversary。
建议仅为单射的部分匹配表，允许建议边不存在；一致性必须对每个实际最大匹配成立。
完整结论为 r_D(c)=min{3/4,3/2-c}，二正则子类为
r_C(c)=min{7/8,7/4-c}，c∈[0,1]，任意有限规模且无加性损失。
因此该精确定义下的原问题状态为 proved，而非仅证明某个局部猜想。

本稿明确归功于 Fàbrega–Muñoz 的 7/8 基线、八环构造和定向证明思路，
Feng 等人的优先规则，以及 Choo 等人和 Jin–Ma 的 Z 构造与线性障碍。
本文的增量是保留“耗尽邻点优先”的建议使用证明、任意错误建议下的环端点界，
以及由此得到的精确前沿和路径上的逐点到达可达性。混合方法不作为新技术。
2026 年 Lindermayr–Megow–Paul 的对应单点到达定理允许分数动作，
不能直接替代这里的随机整数匹配结论。文献筛查不构成优先权保证。
