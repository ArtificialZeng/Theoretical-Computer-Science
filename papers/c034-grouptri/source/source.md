## Exact mathematical reading

For every fixed integer M>=2, establish a uniform classical algorithm and a
constant δ_M>0, such that for EVERY fixed c>0 and EVERY n the following problem
is solved in O_{M,c}(n^(3-δ_M) polylog(n)) charged operations, with a legitimate
bit-model implementation or Θ(log n)-bit word-RAM implementation. The saving
δ_M is independent of c. The polylog factor can be absorbed into a smaller
positive constant saving. Small n and the trivial group must be handled.

G is supplied compactly as a product of cyclic groups Z_(m_i), m_i>=2,
m_i dividing M, with |G|<=n^c. Each edge label is the vector of residues.
The input is a complete tripartite graph with at most n vertices per part A,B,C
and a label w(e) in G on every edge. Decide whether there exists (a,b,c) with
w(a,b)+w(b,c)+w(a,c)=0 in G. Arithmetic, input reading, constructed instances,
output checking, preprocessing, all stages and termination count. A randomized
algorithm must have bounded error on EACH input and a fully charged time cap;
a deterministic algorithm is stronger.

The source also phrases its question relative to the actual selected-entry
matrix primitive H(ε,γ). A positive theorem parametrized by valid ε,γ must
include a legitimate instantiation from an inspected existing algorithm to
settle the unconditional reading here; an assumed new oracle is not a result.
The all-edges/output-witness strengthening is useful only if proved, not required
to silently replace the decision target.

For fixed M, coordinate embeddings reduce the full class to homogeneous
Z_M^r, but all dimensions r=O_c(log n) remain. Fixed tiny dimension, fixed
small |G|, few quotient-zero triangles, few incident residue classes or a
preprocessed universe are not equivalent promises. Missing edges created by
a reduction must be encoded soundly in this complete-input model.
