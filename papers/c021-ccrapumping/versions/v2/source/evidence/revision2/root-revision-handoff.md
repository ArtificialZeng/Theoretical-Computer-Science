## Decisive proof test

The chief uncertainty is the arbitrary-finite-control transfer, not the standard
commutativity test. Reconstruct or refute it first; testing many pattern values
cannot establish nonrecognizability by all finite-state CCRAs.

In a reachable bottom control SCC C, choose a transformation t of minimum rank r.
Since rank(t^2)=rank(t), t permutes its image. e=t^(r!) has image R and fixes R.
For every letter a, eae restricts to a permutation of R by minimum rank. With
N=r!, the blocks e and (eae)^N return to the SAME q in R. Let p reach q. Their
weighted matrices are B0=M_e and Ba=(M_e M_a M_e)^N.

The ALL-word unipotence hypothesis makes B0, Ba, and Ua=M_e M_a M_e unipotent.
The binomial unipotent-root polynomial recovers Ua from Ba. Since M_e^{-1} is
a polynomial in M_e, the unital algebra B generated by these return matrices
equals the original unital algebra A generated by all M_a. As M_p is a unit of
A, lambda M_p B=lambda A; B gamma=A gamma. Thus the block representation is
still minimal on the FULL original weighted space, not merely a quotient losing
the desired noncommutation. The existing one-state obstruction forces the B_j
to commute, hence A and all M_a commute. Check each equality, word order and
zero/constant case. Generator-only unipotence is false as a substitute.

For the converse, commuting unipotent matrices expand by finite binomial sums;
copy each required counter independently for each monomial operand, then take
a read-once final polynomial expression. Commutativity of minimal matrices
is equivalent to f(uabv)=f(ubav) in all contexts by reachability/observability.

For trace testing, every M_w is unipotent iff tr(M_w)=d for all words: apply
the trace identity to w^j, j1..d, and Newton identities/Cayley-Hamilton. The
invariant span of (vec(M_w),1) has dimension <=d^2+1, so testing tr(X)-dc is
a standard rational-series constant test. Minimize first to remove redundant
nonunipotent hidden blocks. Record polynomial BIT bounds, not unit-cost claims.

For explicit patterns, use direct-sum upper-unitriangular embedding-count WAs.
The standard exact reachable/observable-span commutativity test retains basis
words of length <=D-1. Failure gives the claimed adjacent-swap certificate.
On YES, sort the input alphabet: only weakly increasing patterns survive and
f(w)=sum_sorted p c_p product_a binom(|w|_a,m_{p,a}). Allocate one counter
initialized -j for each (p,a,j), j0..m-1; increment it on a. Each product uses
its OWN counters once, and coefficients include reciprocal factorials.
