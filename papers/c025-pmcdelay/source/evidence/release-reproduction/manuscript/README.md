# Manuscript source

Run `python3 build.py` in this directory using an installed TeX distribution
with acmart's normal dependencies. The build performs pdfLaTeX, BibTeX, and
two final pdfLaTeX passes. No network access is used or package installed.

The local `acmart.cls` is the unchanged official class supplied by the user;
`alpha.bst` is the unchanged standard installed BibTeX style, included for
portable alphanumeric bibliography labels. `main.bbl` is a generated input
retained with the source. No figures or experimental implementation are
required for the mathematical argument or compilation.

The retained internal venue assessment is **working_paper**. This is not
a conference decision. This manuscript has not been submitted, uploaded,
or externally peer reviewed. The WRITE phase does not authorize local release:
a separate citation, build, every-page visual, and delivered-ZIP reproduction
review remains required.

The local diagnostic scripts in the project research dossier are supplementary
finite checks. They are not the asymptotic algorithm's proof or a required
manuscript build dependency. An optional later experimental archive was not
part of the frozen mathematical review and is not included here.
