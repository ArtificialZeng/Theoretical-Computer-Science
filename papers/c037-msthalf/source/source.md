# Frozen threshold question: corrupted metric MST below one half

Source: Anand, Gupta, Jayaram, Lee, Vakilian, Approximating Minimum Spanning Trees in Metrics under Semi-Random Corruptions, arXiv:2610.40594v1, Definition2.1–2.3, Theorem1.4–1.5 and Section5. This is a NEW precise threshold-gap question inferred from the source's p<1/4 upper and p>=1/2 lower bounds, not a verbatim author conjecture. Current source status and equivalent claims must be checked in TRIAGE.

For every fixed real p with 0<=p<1/2, does there exist a finite algorithm A_p and constant C_p so that the following holds for every n>=2, every n-point metric d, and every admissible source-model adversary? Independently mark each unordered pair with probability p. The adversary knows d and the marked set and assigns arbitrary finite replacement observations on marked pairs; all other entries remain d, and the observation matrix is symmetric. The algorithm sees only this corrupted matrix, n and p, makes NO queries to true distances, and outputs a spanning tree T with E[sum_{uv in T}d(u,v)] <= C_p max(1,log n) MST(d). Expectation includes the marking and any independent internal randomness of the algorithm. Its procedure must be explicit and finite; computational efficiency is NOT required in this information-theoretic threshold question, matching the source's upper-bound scope. Trivially invalid negative distance observations can be clipped to zero; do not add a metric or triangle-inequality promise on observations.

Resolve the entire quantified affirmative statement or refute it by an actual all-algorithm impossibility at some fixed p<1/2. A method-specific failed certificate or a lower bound only at p>=1/2 is insufficient. Proving only another fixed p<1/4, using true-distance probes, assuming bounded aspect ratio or oblivious independent replacement values, or changing expected true cost to observed cost leaves the original unresolved. A polynomial algorithm would be stronger but is not needed for this exact target. Any negative claim must state and prove its full quantifiers, not substitute a computational conjecture for information-theoretic impossibility.

Nearest prior: O_p(log n) for p<1/4 via minimum almost-dominating trees, and no o(n) for p>=1/2.
