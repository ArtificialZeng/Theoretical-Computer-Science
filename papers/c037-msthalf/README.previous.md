# Minimum Spanning Trees under Semi-Random Corruptions below One Half

**working_paper** · 7 total pages.

[PDF](c037-msthalf_working_paper.pdf) · [Unified index](../../README.md)

Studies minimum spanning trees when each pairwise metric distance is independently marked with probability p and an adversary may replace every marked value arbitrarily after seeing the metric and mask. For every fixed p<1/2, a finite deterministic procedure using only the observed matrix achieves expected true cost O_p(log n) times optimum. It completes the below-half information threshold. The procedure uses exhaustive search; its new ingredient is an all-scale rectangle-to-path metric transfer inequality.
