# Local manuscript build

Build from this directory with `latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex`.
The official unmodified acmart class and ACM bibliography style are included.
The single-column `acmsmall` option uses 11-point single-spaced text with
one-inch US Letter margins to follow the inspected STOC 2027 submission CFP.
This avoids changing the official class's protected manuscript-mode spacing.
Its title/abstract page is
separate as the CFP specifies; the user's stricter twelve-total-page cap applies.
This is a local working paper. Its classification is the actual accepted
mathematical snapshot's `working_paper` assessment, not a venue decision.
No submission, public posting, contact or upload is authorized by this build.
