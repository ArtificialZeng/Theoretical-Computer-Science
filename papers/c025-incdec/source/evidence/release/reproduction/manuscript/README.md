## Build

Run `python3 build.py` from this directory (or invoke the script by path). Requires an existing TeX Live installation providing pdflatex, bibtex, and the standard packages required by official acmart. No packages are installed. The script builds from fresh auxiliary files inside a temporary subdirectory, runs pdflatex, bibtex, and pdflatex twice, then produces `optimal-incdec-working_paper.pdf`, `main.bbl` and build logs. No absolute project or template path is required. Public timestamps are pinned for repeatable local builds.

The unmodified official acmart v2.20 class and its matching dtx source are included. `alphaurl.bst` is the unchanged installed standard bibliography style. The class's acmsmall option supplies single-column default single spacing, with public 11pt and one-inch letterpaper geometry settings for the current STOC submission guidelines. This is a local submission-format working paper, not a camera-ready ACM proceedings article. No copyright transfer, venue acceptance, DOI, human verification, ORCID or video is asserted.

The complete mathematical proof is in the article. Experiments used during discovery are not premises of the theorem.
